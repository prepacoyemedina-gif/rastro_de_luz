# rastro_de_luz
Rastro de Luz es un sitio web que orienta a familias que buscan a una persona desaparecida en México. Ofrece información verificada y alertas oportunas con apoyo de IA, sin sustituir a las autoridades ni garantizar resultados. Protege los datos personales y recomienda confirmar la información con fuentes oficiales y apoyo humano.
